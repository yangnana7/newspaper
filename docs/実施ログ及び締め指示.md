# 仕上げ（即反映パッチ）— 再発ゼロ化の二重化

## 1) DB側でもデフォルト＆空文字防止（ベルト＆サスペンダー）

アプリ側で `COALESCE` 済みでも、将来のコード回り込みを潰すため**DBで最終ガード**を足します。既存データを先に整えてから制約追加。

```patch
*** Begin Patch
*** Add File: db/migrations/2025-08-27_event_participant_role_default.sql
+-- Harden role on event_participant table:
+-- 1) normalize any NULL/empty roles to 'participant'
+-- 2) set DEFAULT at DB level
+-- 3) optional CHECK to forbid empty string going forward
+
+UPDATE event_participant
+SET role = 'participant'
+WHERE role IS NULL OR role = '';
+
+ALTER TABLE event_participant
+  ALTER COLUMN role SET DEFAULT 'participant';
+
+-- If you want stricter guard (safe when existing rows have no empty role):
+DO $$
+BEGIN
+  IF NOT EXISTS (
+    SELECT 1 FROM pg_constraint
+    WHERE conname = 'event_participant_role_not_empty'
+  ) THEN
+    ALTER TABLE event_participant
+      ADD CONSTRAINT event_participant_role_not_empty
+      CHECK (length(role) > 0);
+  END IF;
+END $$;
+
*** End Patch
```

> これで「NULL／空文字」は**DBが必ず `participant` に矯正**。将来のバイパス経路でも落ちません。

## 2) SQL側のCOALESCEを空文字まで拾うよう強化（コードと一致）

（すでに近い実装ですが、**空文字**も拾う形に統一）

```patch
*** Begin Patch
*** Update File: scripts/ingest_events.py
@@
-        conn.execute(
-            "INSERT INTO event_participant (event_id, role, ent_id) VALUES (%s, COALESCE(%s,'participant'), %s) "
-            "ON CONFLICT DO NOTHING",
-            (ev_id, role_value, ent_id),
-        )
+        conn.execute(
+            "INSERT INTO event_participant (event_id, role, ent_id) "
+            "VALUES (%s, COALESCE(NULLIF(%s, ''), 'participant'), %s) "
+            "ON CONFLICT DO NOTHING",
+            (ev_id, role_value, ent_id),
+        )
*** End Patch
```
