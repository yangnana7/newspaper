## 5) EXPLAIN ANALYZE（Index Scanを目視）

```bash
psql "$DATABASE_URL" -c "
EXPLAIN (ANALYZE, COSTS, VERBOSE, BUFFERS, TIMING)
WITH q AS (
  SELECT emb FROM chunk_vec
  WHERE embedding_space='${EMBED_SPACE}'
  ORDER BY chunk_id DESC LIMIT 1
)
SELECT d.doc_id
FROM chunk_vec v, q
JOIN chunk c ON c.chunk_id=v.chunk_id
JOIN doc   d ON d.doc_id=c.doc_id
WHERE v.embedding_space='${EMBED_SPACE}'
ORDER BY v.emb <=> q.emb
LIMIT 10;"
```

# 参考：今回観測したエラーと原因

* `psycopg.OperationalError: fe_sendauth: no password supplied`（127.0.0.1:5432/TCP）→ **パスワード未指定**。DSNに `user@host:port/db` と `PGPASSWORD` を設定してください。
* `psql: FATAL: database "yang_server" does not exist`（Unixソケット）→ **`DATABASE_URL` 未設定**で psql がOSユーザ名DBへ接続しようとした。環境変数を必ず書く。
* 仕上げ手順が `chunk.emb` を参照 → **スキーマは `chunk_vec`**。`embedding_space` フィルタとcosine用オプクラで統一を。
