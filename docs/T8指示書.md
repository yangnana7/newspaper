# T8: Backup/Restore ＋ systemd（実装手順・受入基準つき）

## 0) 仕様（最小構成）

* **対象DB**: `newshub`（PostgreSQLローカル）
* **方式**: `pg_dump` カスタム形式（`.dump`、内部圧縮）＋SHA256
  低負荷実行：`ionice -c3` ＋ `nice -n 19`
* **保存先**: `/var/backups/newshub`（`root:postgres`、`0750`）
* **世代管理**: 日次保持 21日（必要なら拡張）
* **検証**: 週1回「リストア稼働確認」（`newshub_verify` 一時DBへ `pg_restore`）
  → 件数・インデックス・拡張の存在チェック
* **スケジューラ**: `systemd timer`

  * 日次バックアップ: 毎日 03:30
  * 週次検証: 毎週 日曜 04:10
* **含める構成バックアップ**:
  `/etc/default/mcp-news`、`/etc/systemd/system/*mcp-news*`、`/home/yang_server/newspaper`（アプリ一式）

## 1) ディレクトリ/権限

```bash
set -Eeuo pipefail
sudo install -o root -g postgres -m 0750 -d /var/backups/newshub
sudo install -o root -g postgres -m 0750 -d /var/backups/newshub/app
```

## 2) バックアップスクリプト `/usr/local/bin/newshub-backup.sh`

```bash
sudo tee /usr/local/bin/newshub-backup.sh >/dev/null <<'SH'
#!/usr/bin/env bash
set -Eeuo pipefail

ENV_FILE=/etc/default/mcp-news
BACKUP_DIR=/var/backups/newshub
APP_DIR=/home/yang_server/newspaper

# 低負荷化ランチャ
run_low() { ionice -c3 nice -n 19 "$@"; }

# DSN取得
eval "$(grep -E '^(DATABASE_URL)=' "$ENV_FILE")"
if [ -z "${DATABASE_URL:-}" ]; then
  echo "[ERR] DATABASE_URL not set"; exit 1
fi

ts="$(date +%Y%m%d-%H%M%S)"
db_dump="${BACKUP_DIR}/newshub-${ts}.dump"
sha_file="${db_dump}.sha256"

# DBバックアップ
run_low pg_dump --dbname="$DATABASE_URL" --format=custom --blobs --compress=9 --file="$db_dump"
sha256sum "$(basename "$db_dump")" | (cd "$BACKUP_DIR" && cat > "$(basename "$sha_file")")

# 構成/アプリの同期アーカイブ（軽量）
tar czf "${BACKUP_DIR}/app/app-${ts}.tgz" \
  /etc/default/mcp-news \
  /etc/systemd/system/mcp-news.service \
  "$APP_DIR" 2>/dev/null || true

# 日次保持（21日）: .dump と .tgz を古い順に削除
find "$BACKUP_DIR" -type f -name 'newshub-*.dump' -mtime +21 -delete
find "$BACKUP_DIR/app" -type f -name 'app-*.tgz' -mtime +21 -delete

echo "[OK] backup done: ${db_dump}"
SH
sudo chmod 0755 /usr/local/bin/newshub-backup.sh
```

## 3) 週次検証 `/usr/local/bin/newshub-verify.sh`

```bash
sudo tee /usr/local/bin/newshub-verify.sh >/dev/null <<'SH'
#!/usr/bin/env bash
set -Eeuo pipefail

ENV_FILE=/etc/default/mcp-news
BACKUP_DIR=/var/backups/newshub
VERIFY_DB=newshub_verify

eval "$(grep -E '^(DATABASE_URL)=' "$ENV_FILE")"
if [ -z "${DATABASE_URL:-}" ]; then
  echo "[ERR] DATABASE_URL not set"; exit 1
fi

# 最新ダンプを特定
latest="$(ls -1t ${BACKUP_DIR}/newshub-*.dump 2>/dev/null | head -n1)"
[ -n "$latest" ] || { echo "[ERR] no dumps found"; exit 1; }

# 検証DB作成→リストア→簡易チェック→破棄（拡張はダンプに含まれる想定）
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -c "DROP DATABASE IF EXISTS ${VERIFY_DB};"
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -c "CREATE DATABASE ${VERIFY_DB};"

pg_restore --clean --if-exists --no-owner --no-privileges \
  --dbname="${DATABASE_URL%/*}/${VERIFY_DB}" "$latest"

# 代表チェック
psql "${DATABASE_URL%/*}/${VERIFY_DB}" -Atc "
SELECT 'doc', count(*) FROM doc
UNION ALL
SELECT 'chunk', count(*) FROM chunk
UNION ALL
SELECT 'chunk_vec', count(*) FROM chunk_vec;
" | sed 's/\t/: /g'

# cosine HNSW があれば indexdef に vector_cosine_ops を含むことを確認（存在しなくてもOK）
psql "${DATABASE_URL%/*}/${VERIFY_DB}" -Atc "
SELECT indexname, indexdef
FROM pg_indexes
WHERE tablename='chunk_vec' AND indexdef ILIKE '%vector_cosine_ops%';
"

# 検証DB削除
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -c "DROP DATABASE IF EXISTS ${VERIFY_DB};"
echo "[OK] verify done for ${latest}"
SH
sudo chmod 0755 /usr/local/bin/newshub-verify.sh
```

## 4) systemd ユニット/タイマー

### バックアップ（毎日 03:30）

```ini
# /etc/systemd/system/newshub-backup.service
[Unit]
Description=Newshub logical backup (daily)

[Service]
Type=oneshot
User=postgres
Group=postgres
ExecStart=/usr/local/bin/newshub-backup.sh
Nice=19
IOSchedulingClass=idle
```

```ini
# /etc/systemd/system/newshub-backup.timer
[Unit]
Description=Daily backup for newshub

[Timer]
OnCalendar=*-*-* 03:30:00
Persistent=true
Unit=newshub-backup.service

[Install]
WantedBy=timers.target
```

### 週次検証（毎週 日曜 04:10）

```ini
# /etc/systemd/system/newshub-verify.service
[Unit]
Description=Newshub restore verification (weekly)

[Service]
Type=oneshot
User=postgres
Group=postgres
ExecStart=/usr/local/bin/newshub-verify.sh
Nice=19
IOSchedulingClass=idle
```

```ini
# /etc/systemd/system/newshub-verify.timer
[Unit]
Description=Weekly restore verification for newshub

[Timer]
OnCalendar=Sun *-*-* 04:10:00
Persistent=true
Unit=newshub-verify.service

[Install]
WantedBy=timers.target
```

### 有効化

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now newshub-backup.timer newshub-verify.timer
sudo systemctl list-timers --all | egrep 'newshub-(backup|verify)'
```

## 5) 受入基準（T8 Done の定義）

* `systemctl list-timers` に **newshub-backup.timer / newshub-verify.timer** が *active* 表示。
* `/var/backups/newshub/` に当日生成の `newshub-YYYYMMDD-HHMMSS.dump` と `.sha256` が存在。
  `sha256sum -c` が **OK**。
* `sudo systemctl start newshub-verify.service` を手動実行して成功。
  ログに `doc/chunk/chunk_vec` の件数が表示され、最後が **\[OK] verify done**。
* （任意）`/var/backups/newshub/app/app-YYYYMMDD.tgz` が生成され、`/etc/default/mcp-news` と `mcp-news.service` を含む。

## 6) リストア手順（手動検証／障害時）

### 手動検証（本番稼働を止めない検証）

```bash
# 検証は newshub-verify.sh が自動化済（週次）。手動実行も可：
sudo systemctl start newshub-verify.service
journalctl -u newshub-verify.service -n 100 --no-pager
```

### 本番へのフルリストア（障害対応）

> 事前に最新ダンプを特定しておくこと。
>
> 1. 停止 → 2) DB初期化 → 3) リストア → 4) 起動 → 5) スモーク

```bash
latest=$(ls -1t /var/backups/newshub/newshub-*.dump | head -n1)
sudo systemctl stop mcp-news.service ingest.timer embed.timer || true

# 既存DBを入れ替え
eval "$(grep -E '^DATABASE_URL=' /etc/default/mcp-news)"
sudo -u postgres psql -v ON_ERROR_STOP=1 -c "DROP DATABASE IF EXISTS newshub;"
sudo -u postgres psql -v ON_ERROR_STOP=1 -c "CREATE DATABASE newshub;"
pg_restore --clean --if-exists --no-owner --no-privileges --dbname="$DATABASE_URL" "$latest"

sudo systemctl start mcp-news.service ingest.timer embed.timer

# スモーク
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:3011/           # 404
curl -s -o /dev/null -w '%{http_code}\n' "http://127.0.0.1:3011/search?q=ping"  # 200/204
```

## 7) 追加オプション（必要に応じて）

* **オフサイト二重化**：`rclone` などで `/var/backups/newshub` を夜間同期。
* **暗号化**：GPGで `.dump` を受信者鍵で暗号化（運用が厳しければ後日）。
