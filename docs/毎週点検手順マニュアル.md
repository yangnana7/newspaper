### C. DB/pgvector/HNSW（cosine固定）チェック

1. **pgvector バージョン**

```bash
psql "$DSN" -Atc "SELECT extname, extversion FROM pg_extension WHERE extname='vector';"
# 0.5.0 以上で HNSW 利用可（0.5未満ならパッケージ更新が必要）
```

2. **既存インデックスの一覧と L2 残骸の掃除**

```bash
psql "$DSN" -Atc "SELECT indexname, indexdef FROM pg_indexes WHERE tablename='chunk_vec';"
# L2 残骸があれば削除（存在しない場合は何もしない）
psql "$DSN" -v ON_ERROR_STOP=1 -Atc "
DO \$\$
DECLARE r record;
BEGIN
  FOR r IN
    SELECT indexrelid::regclass AS idx
    FROM pg_index i
    JOIN pg_class c ON c.oid=i.indexrelid
    WHERE pg_get_indexdef(i.indexrelid) ILIKE '%vector_l2_ops%'
  LOOP
    EXECUTE 'DROP INDEX IF EXISTS '||r.idx;
  END LOOP;
END
\$\$;"
```

3. **cosine HNSW の作成（`e5-multilingual` 空間の例）**

> 権限で弾かれる場合は `sudo -u postgres psql`（superuser）で実行。

```bash
psql "$DSN" -v ON_ERROR_STOP=1 -c "
CREATE INDEX CONCURRENTLY IF NOT EXISTS idx_chunk_vec_cos_e5
ON chunk_vec USING hnsw (emb vector_cosine_ops)
WHERE embedding_space = 'e5-multilingual';
"
-- 検証
psql "$DSN" -Atc "SELECT indexname, indexdef FROM pg_indexes WHERE tablename='chunk_vec' AND indexname='idx_chunk_vec_cos_e5';"
```

> 参考：別空間（例：`bge-m3`）を併用している場合は、同様に `embedding_space='bge-m3'` で作成。

### D. データ健全性サマリ

```bash
psql "$DSN" -Atc "
SELECT
  (SELECT count(*) FROM doc)      AS doc_cnt,
  (SELECT count(*) FROM chunk)    AS chunk_cnt,
  (SELECT count(*) FROM chunk_vec)AS chunk_vec_cnt,
  (SELECT to_char(max(published_at),'YYYY-MM-DD HH24:MI') FROM doc) AS latest_pub
;"
# ソース別・最近7日
psql "$DSN" -F $'\t' -Atc "
SELECT source, count(*)
FROM doc
WHERE published_at >= now() - interval '7 days'
GROUP BY 1 ORDER BY 2 DESC
LIMIT 20;"
```

### E. ENV ガード（固定値）と重複の整理

```bash
# 必須キーが揃っているか
egrep -n '^(DATABASE_URL|APP_BIND_HOST|APP_BIND_PORT|EMBEDDING_SPACE|EMBED_SPACE|UI_ENABLED)=' "$ENV_FILE" || true

# EMBED_SPACE の重複を整理（同値で1行に統一）
tmp=$(mktemp)
awk -F= '
  BEGIN{seen1=seen2=0}
  /^EMBEDDING_SPACE=/{ if(!seen1++){print; next} }
  /^EMBED_SPACE=/{ if(!seen2++){print; next} }
  {print}
' "$ENV_FILE" > "$tmp" && sudo install -m 0644 "$tmp" "$ENV_FILE" && rm -f "$tmp"

# 値の同一化（EMBEDDING_SPACE を優先）
val="$(grep -E '^EMBEDDING_SPACE=' "$ENV_FILE" | cut -d= -f2-)"
[ -n "$val" ] && sudo sed -i "s/^EMBED_SPACE=.*/EMBED_SPACE=$val/" "$ENV_FILE"
```

> 変更後は `systemctl restart mcp-news.service` を忘れずに。

### G. 週次メンテ（任意）：cosine HNSW 再作成ジョブ

> 競合を避けるため夜間に。PostgreSQL が 0.5+ であることが前提。

`/etc/systemd/system/newshub-reindex.service`

```ini
[Unit]
Description=Rebuild cosine HNSW index for chunk_vec (weekly)

[Service]
Type=oneshot
EnvironmentFile=/etc/default/mcp-news
ExecStart=/usr/bin/psql ${DATABASE_URL} -v ON_ERROR_STOP=1 -c "CREATE INDEX CONCURRENTLY IF NOT EXISTS idx_chunk_vec_cos_e5 ON chunk_vec USING hnsw (emb vector_cosine_ops) WHERE embedding_space='e5-multilingual';"
```

`/etc/systemd/system/newshub-reindex.timer`

```ini
[Unit]
Description=Weekly HNSW (cosine) index maintenance

[Timer]
OnCalendar=Sun *-*-* 04:00:00
Persistent=true
Unit=newshub-reindex.service

[Install]
WantedBy=timers.target
```

有効化:

```bash
systemctl daemon-reload
systemctl enable --now newshub-reindex.timer
systemctl list-timers --all | grep newshub-reindex
```
